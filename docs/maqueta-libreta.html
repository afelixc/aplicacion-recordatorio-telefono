Libreta con carpetas

  1. En el Chat, el texto de arriba queda chico y Ejemplos va al lado, como un botoncito.
  2. Abajo, dos botones grandes del mismo tamaño y distinto color: Cargar a mano (azul) y Libreta (amarillo). El que tocás se agranda y entra.
  3. En la libreta están tus carpetas: Impresora, Auto… Con ＋ Nueva carpeta creás otra con el nombre que quieras.
  4. Dentro de una carpeta, las cosas van numeradas: 1, 2, 3…
  5. Solo se tilda tocando el cuadradito. Si tocás el renglón, se marca y aparecen ▲ ▼ para subirlo o bajarlo, 🔔 para pasarlo a recordatorio y 🗑 para borrarlo.
  6. Abajo: escribís y tocás el ✓ verde para anotar, o tocás el 🎤 para dictar.
Probalo (hace de cuenta que hablaste dentro de la carpeta abierta):

Lo que ya anotaste

Las cosas que ya cargaste en la libreta de antes van a quedar en una carpeta llamada General, así no se pierde nada.
